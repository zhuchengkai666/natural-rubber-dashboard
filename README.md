# 天然橡胶只读数据看板

这是本地验收后发布的静态快照：保留页面、图表和查看筛选，不提供编辑、数据库写入、导出或复制图片。

源数据采集与计算留在本机；此仓库不包含DuckDB数据库、原始文件、备份、运行环境或凭据。页面中的数据按其来源实际截至日期展示，网站发布时间不代表所有来源都有新数据。

`site/version.json` 为真实发布内容版本，`site/static-manifest.json` 提供文件哈希。提交后GitHub Actions校验整个静态目录，再部署到GitHub Pages。没有每天重复发布旧数据的云端定时器。

公开网页及JSON均可被访问和下载。首次上线为试运行，国内访问效果需在实际使用网络验证。
